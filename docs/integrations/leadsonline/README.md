# LeadsOnline Integration References

This folder contains the existing Canadian pawn API reference PDF and SOAP XML
request examples, previously stored in the repository's root `SOAP` folder.
Original filenames and file contents are preserved.

The examples cover transaction submission, do-not-buy checks, no-transaction-day
notifications, and image uploads. These are reference materials, not executable
application code or configuration.

The application's integration code is in
[`src/main/modules/xml-reports`](../../../src/main/modules/xml-reports), including
the SOAP client, endpoint configuration, payload mapping, and report service.
